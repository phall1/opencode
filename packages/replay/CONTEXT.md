# Replay vocabulary

| Term                | Meaning                                                                                         |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| Episode             | One finite, bounded native agent execution and its frozen evidence.                             |
| Capsule             | A self-contained immutable episode archive with a content identity.                             |
| Tape                | Ordered captured component results, matched to their original requests.                         |
| Occurrence          | A tool invocation's serial position within one episode.                                         |
| Component replay    | Re-execution using captured provider and tool results rather than live components.              |
| World               | The bounded environment visible to an episode's supported tools.                                |
| Checkpoint          | A paired world and conversation boundary from which a continuation may begin.                   |
| Final-idle boundary | The completed episode's quiescent end, with no pending admitted work.                           |
| Fork                | A new native conversation lineage paired with an isolated copy of the checkpoint world.         |
| Trajectory          | The new observations and actions generated by a continuation; not reused old results.           |
| Child capsule       | A replayable episode capsule containing its immutable parent and its own continuation evidence. |
| Verifier            | A versioned judgment over specified frozen evidence.                                            |
| Measurement         | A separately identified verifier result that does not alter the original episode.               |
| Coverage            | The component and world behavior an archive actually captures and can restore.                  |
